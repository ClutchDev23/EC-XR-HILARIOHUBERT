* **Descripción breve del proyecto desarrollado:** 
Escenario de entrenamiento XR desarrollado en Unity integrando configuración OpenXR, físicas de manipulación directa y mecánicas de interacción a distancia.
* **Funcionalidades implementadas:** 
  - Escenario 3D con límites visuales.
  - Manipulación física de objetos mediante `XR Grab Interactable`.
  - Interacción a distancia con `XR Simple Interactable` (botón para encender luz).
  - Reto libre: Sistema de locomoción mediante Teletransporte (`Teleportation Area`).
* **Controles o instrucciones (XR Device Simulator):** 
  - Mantener clic derecho + W,A,S,D para mover la cámara.
  - Presionar `Shift Izquierdo` o `Espacio` para activar el control virtual.
  - Tecla `G` (Grip) para agarrar y manipular objetos.
  - Clic Izquierdo (Trigger) para interactuar a distancia con la luz.
* **Tecnologías y paquetes utilizados:** Unity (URP), XR Plugin Management, OpenXR, XR Interaction Toolkit (Starter Assets).
